# Code of Conduct

FEED follows the **Contributor Covenant, version 2.1** as its code of
conduct.

The full text of the Covenant is published at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — filing issues, opening pull requests,
joining discussions, contributing code — you agree to abide by its terms.

## Reporting

If you experience or witness behavior in violation of the Covenant in a
FEED-affiliated space (this repository, project discussions, mailing
lists, events), please report it privately to the maintainer, Matt
Geiger of Temple Consulting, LLC., at
[matt@templepdx.com](mailto:matt@templepdx.com).

Reports will be reviewed and investigated promptly. All maintainers are
obligated to respect the privacy of reporters.

## Enforcement

Maintainers will follow the Covenant's Enforcement Guidelines
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines)
when determining responses to reported behavior. Consequences range from
a private warning to a permanent ban from project spaces, scaled to the
severity and pattern of the behavior.
