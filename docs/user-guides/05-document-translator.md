# Document Translator

Document Translator helps staff turn English DOCX files into client-ready translated documents.

## What It Is For

Use Document Translator for forms, notices, flyers, and other Word documents that clients need in another language.

It is designed for DOCX files. PDF translation is not the main workflow here.

## Before You Upload

Check that the English document is final enough to translate.

Small edits after translation may require new translations, so it is best to review the source document first.

## How To Translate A Document

1. Open Document Translator.
2. Select Upload Document.
3. Choose a DOCX file.
4. Open the translate action for that document.
5. Select the languages needed.
6. Start translation.
7. Download the finished files when they are ready.

## When To Use Advanced Options

Use advanced options when staff need more control over what gets translated or how English appears with translated text.

If you are not sure, use the basic workflow first.

## What To Do If A Translation Fails

1. Wait a moment and try again.
2. Check whether other languages worked.
3. If only one language keeps failing, ask an administrator to review the issue.

Some failures are temporary provider problems. Your original document is not lost.
