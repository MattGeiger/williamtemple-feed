# Shopping List Builder

Shopping List Builder is where staff design printable shopping list templates.

## Who Should Use It?

Use the Builder if you are responsible for how the printed list looks or what information appears on it.

If you only need to print an existing list, use [Shopping Lists](07-shopping-lists.md).

## What You Build

You build a reusable template, not a one-time list.

A template can include text, dates, form fields, lines, a legend, and inventory sections. Inventory sections fill in with current pantry items each time the list is printed.

## Find Your Way Around

The Builder has three parts.

![Shopping List Builder with the Insert panel, the page, and the Page settings](/help-screenshots/shopping-list-builder-canvas.png)

- **Insert** (left): everything you can add to the page.
- **The page** (middle): what will print.
- **Settings** (right): the **Page** tab changes the whole page. The **Component** tab changes the item you selected.

The row above holds the template name, **Open**, the preview language, **Save Template**, and **Download PDF**.

## Start A Template

When the page is blank, the Builder offers your saved templates.

![A blank page offering saved templates to start from](/help-screenshots/shopping-list-builder-start.png)

1. Click a saved template to start from it, or begin adding items for a blank start.
2. Type a name for the template at the top.
3. Click **Save Template** when you are ready.

A dot on **Save Template** means you have changes that are not saved yet.

To open a different template later, click **Open**. **New blank template** is at the bottom of that menu.

## Add Things To The Page

1. Click an item in **Insert**. It appears on the page, already selected.
2. Or drag it to the spot where you want it.

When you add a text block, just start typing. The cursor is already in the text.

To add every inventory section at once, click **Add all**.

## Change An Item

Click an item on the page. Its settings open in the **Component** tab.

![An inventory table selected, with its settings on the right](/help-screenshots/shopping-list-builder-component.png)

- Double-click an item to jump straight to its text.
- Use the small bar above the selected item to copy or delete it.
- Click an empty part of the page to return to the **Page** tab.

### Make Every Table Match

Set up one table the way you want it. Then click **Apply to all**.

Every other table takes the same columns and style. Titles, rows, and limits do not change.

## Guided Mode And Freeform Mode

Guided mode lines items up for you and keeps them from overlapping. Start here.

Freeform mode lets you place items anywhere. Use it when Guided mode gets in the way of a specific layout.

## Choose A Page Layout

Open the **Page** tab and choose a **Layout**.

- **Full** — one wide column.
- **Split** — two columns side by side.
- **Grid** — several small slips on one sheet.

### Make Slips With A Grid

Use Grid when you want small forms or tickets to cut apart.

![A grid page with the same form repeated in each square](/help-screenshots/shopping-list-builder-grid.png)

1. Choose **Grid**.
2. Choose a **Grid size**: 2 × 2 makes four slips, 2 × 3 makes six, 2 × 4 makes eight.
3. Choose how the **Squares** fill:
   - **Duplicate all** — build one square. Every square repeats it.
   - **Individual** — each square has its own content. Click a square, then add items to it.

Things to know about Grid:

- **A grid is always one page.** Choose **Make 2-sided** to print the same page on the back.
- **Each square has a limit.** If something will not fit in its square, the Builder does not add it and tells you why. Remove something, shorten it, or choose a grid with larger squares.
- **There is no header or footer.** Everything sits inside a square. Put a title inside the square if the slip needs one.
- **Freeform stays inside the square.** You can place items anywhere within a square, but not outside it.

## Cut Marks

Split and Grid pages print dashed lines that show where to cut.

To hide them, open the **Page** tab and turn off **Cut marks**.

## See The Whole Page

Use the zoom controls above the page.

- Click the percentage to choose **Fit width**, **Fit whole page**, or **100%**.
- Use the plus and minus buttons for small changes.

## Keyboard Shortcuts

Click an item on the page first.

| Press | To |
|---|---|
| Delete | Remove the item |
| Ctrl + D (⌘ D on a Mac) | Copy the item |
| Ctrl + Z (⌘ Z on a Mac) | Undo the last change |
| Esc | Deselect |
| Arrow keys | Nudge the item |

## Why Inventory Sections Stay Connected

Inventory sections use live pantry data.

Item names, limits, and stock status come from Inventory. This keeps printed lists accurate when the pantry changes.

If you change a limit in the Builder, FEED updates the food item or category too.

## Translation Settings

Use Translation Settings when a printed list needs translated text, English text, or both.

For many rows, showing the translated item with the English name helps staff and clients confirm they are talking about the same food.

To check a language before printing, choose it in the preview language menu at the top.

## What To Check Before Printing

- The right template is open.
- Everything fits on the page. A red note under the page tells you if something does not.
- Limits look correct.
- Translation settings match the client need.
- The downloaded PDF looks like the page in the Builder.
