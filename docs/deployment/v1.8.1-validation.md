# v1.8.1 — Chrome shell frost correction

Date: 2026-09-14 (America/Los_Angeles).

## Scope and cause

CSS declaration ordering only, plus matching package versions and release
notes. No dependency, database migration, auth, API or deployment configuration
changes. Both images must carry 1.8.1. Existing production AI settings remain
unchanged; the same-day 1.8.0 catalogue audit and feature validation remain the
baseline. Dormant report infrastructure stays isolated as previously documented.

Production 1.8.0 served `index-CJFBoG8I.css` with only the prefixed header
backdrop declaration. Chrome computed `none` while Safari rendered the blur.
The Analytics date banner retained both declarations. A direct optimizer
experiment reproduced the loss and showed that placing the standard property
last preserves both. This avoids layout changes, opacity compensation, or a
dependency/build-configuration change.
